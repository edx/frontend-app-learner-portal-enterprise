# Turn-stream golden fixtures

These are the portal's copies of the five canonical golden `.sse` files. The canonical copies live in enterprise-access at `enterprise_access/apps/personalized_search/tests/fixtures/`, generated by the orchestrator with fake steps (tech spec "Worked examples"). The portal reducer and the fixture transport consume these copies.

**Status:** `normal_turn`, `off_topic_turn` and `no_match_turn` are byte-for-byte copies of the enterprise-access goldens. `error_turn` is a copy of `model_failed_turn`. `degraded_turn` is still **provisional** (hand-authored from the tech spec), because the spec's degraded mode isn't built in enterprise-access yet.

To refresh after the goldens change:

1. Copy the `.sse` files over these, byte for byte.
2. Run `node src/components/dashboard/main-content/personalized-search/core/stream/__fixtures__/syncFixtures.js "enterprise-access@<sha>"`.
3. Run the `personalized-search` tests and update the reducer snapshots if the contract changed.

A contract change updates both repos' copies in the same pair of PRs.
